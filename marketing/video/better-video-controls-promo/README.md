# Better Video Controls — promo

25 seconds, 1920 × 1080, 30 fps. English benefit captions, real extension interaction, and an original instrumental bed. No narration; all messaging works with sound muted.

## Deliverables

- `better-video-controls-promo-1080p.mp4`: upload master with music.
- `better-video-controls-promo-silent.mp4`: same edit without audio, for website embedding.
- `thumbnail.jpg`: first benefit frame for the video thumbnail.
- `index.html`: editable HyperFrames composition.
- `DESIGN.md`: palette, typography, motion, and creative direction.

## Edit

```sh
npm run dev
npm run check
npm run render -- --output better-video-controls-promo-1080p.mp4 --fps 30 --quality high --workers 2
```

The scripts pin HyperFrames 0.8.30. All media and GSAP are local. Preview can also run persistently with `npx hyperframes@0.8.30 preview --background`.

## Footage and accuracy

The browser recording uses the repository's built Chrome extension, version 1.0.9, in an isolated Chrome for Testing profile. It operates on an ordinary local HTML5 video page. The surrounding demo page was created for this promo; it is not a recording of YouTube, Instagram, or TikTok. Native video timing and the extension overlay are captured as rendered, not animated replicas. Gesture illustrations and copy are editorial overlays.

The footage is paused between seek actions to make movement through the timeline apparent. The only scripted time assignment is the starting position (3 seconds); subsequent position changes are caused by actual browser wheel input. `assets/capture-log.json` records the resulting positions and modifier labels. The first failed capture trials were discarded. The successful capture logged a background page error (`Cannot read properties of null (reading 'get')`); all demonstrated controls nevertheless worked. The promo composition itself passes runtime checks with no warnings.

The capture helper uses local Playwright and Chrome paths from the production machine; update those paths to re-record on another machine. Re-rendering the finished composition does not need Playwright or the extension.
